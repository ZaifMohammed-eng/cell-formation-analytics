## R_LS process limit
- Pooled across protocols, R_LS vs cycle life gives r = -0.84 (RT), matching the paper. Within a protocol the link holds only for baseline cells (r = -0.75, p = 0.012, n = 10); for fast cells r = -0.08 (p = 0.84). The screen is only justified for baseline formation.
- At the current 145 mOhm limit: R_LS yield 95.9%, P(cell misses spec) 12.2%, P(96s4p pack misses spec) 57%.
- Scrap + warranty cost per good cell at 145 mOhm: $0.77 (cell view), $3.43 (pack view). Cost-optimal limit: 142.0 mOhm ($0.57) on cells, 141.0 mOhm ($0.46) on packs. The weakest-link pack view makes a loose cell limit far more expensive than the cell view suggests.
